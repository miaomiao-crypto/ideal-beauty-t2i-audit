# 概念资源库三层结构（2026-11-13）

## 口径与命名
- 原 75 条（CC001–CC075）在本论文中称"**前期整理的候选文化记录**"，不是已验证的文化概念清单。
- 每条标注**来源核查状态**：已核对 / 待核实 / 已排除（namus CC039、honra CC066）。
- **同主题 ≠ 重复概念**：先标"主题关联"，再判含义、语境、实践是否相同，不直接合并或扣减数量。
- **女性劳动/工匠/渔民等不一定对应独有文化概念**：另建"实践与角色资源表"，用 ID 与概念关联，避免硬造概念。

## 三层结构
1. **概念库**（层1）：`原75条核查表.csv` + `新增概念.csv`；ID=CC001–CC075 与 NC001–NC0xx 分离。
2. **实践与角色资源**（层2）：`实践与角色资源.csv`；PR001–PR0xx，用"关联概念ID"挂到概念。
3. **多维提示卡**（层3）：`提示卡_示范批.csv`；PC-<concept>-<n>，卡片ID 与概念ID 分离；每概念 2–4 种实践变体。

## 提示卡七维（按需组合，不硬填满）
文化含义 + 角色 + 任务与工具 + 互动关系 + 人格表达 + 情境表情 + 场景（+镜头要求）。
- 年龄/性别呈现为**可控变体**，不固定"女性=照护、男性=技艺"。
- 人格/表情**不机械分配正面特质**，须配合可见行为与情境。
- 照护、休闲、消费、微笑都是保留表达，新卡是**拓展选择**而非替换。

## 验证口径（统一）
- 基线唯一：默认理想人物；对照：旧品格引导 vs 新多维提示。
- v7 对职业/人格弱、无表情字段：这三项走阶段1描述核查 + 少量人工；行动/互动/场景/文化走 v7 机器编码。
- 未做效果验证，不宣称已证明。
